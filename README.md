# MILLIMETRE ERP

Production-ready Next.js foundation for the MILLIMETRE manufacturing and enterprise operations platform.

## Stack
- Next.js + TypeScript
- Supabase
- Vercel

## Local development
```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add the Supabase public URL and anonymous key.

## Deployment
Connect this repository to Vercel. The default production URL can use the free `vercel.app` domain initially.
